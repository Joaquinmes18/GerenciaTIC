Arquitectura de Defensa en Profundidad

PhishShield no es un simple filtro. Es un pipeline de seguridad completo que va desde el navegador hasta los LLMs más avanzados.

1. Extensión Cliente

Escaneo del DOM en tiempo real. Captura el contexto visual y enlaces de Gmail/Facebook e inyecta la pantalla de bloqueo (Red Overlay).

2. Core Backend

Desarrollado en FastAPI. Orquesta las peticiones, maneja la autenticación OAuth y gestiona la cola de análisis de forma asíncrona y escalable.

3. MCP Server

Integra Google Gemini 2.5 Flash para el análisis semántico y la API de Safe Browsing para la validación de URLs maliciosas.

Motor de Razonamiento Semántico

Los filtros tradicionales se basan en listas negras estáticas. PhishShield utiliza el Model Context Protocol (MCP) para razonar sobre la intención del atacante.

  • Cero Latencia Perceptible

    Gracias al procesamiento asíncrono de FastAPI y Gemini 2.5 Flash, las decisiones de bloqueo ocurren en milisegundos.

  • Safe Browsing API Integrado

    El servidor MCP cruza los datos semánticos con la base de datos de amenazas globales de Google en tiempo real.

  • Bloqueo a Nivel DOM

    Si se detecta peligro, la extensión inyecta código que desactiva botones y enlaces, previniendo el robo de credenciales.
