¿Cómo funciona?

Gemini, MCP y fallback local

PishShield toma el correo de Gmail, extrae el contexto, analiza el contenido con Gemini y valida URLs con MCP antes de devolver una respuesta final.

1. Llega el correo

La extensión recoge subject, body, sender y metadatos del mensaje nuevo.

2. Gemini lo clasifica

Se envía a Gemini 2.5 Flash via API v1beta para obtener verdict, confidence, reason e indicators.

3. Verifica URLs y dominios

MCP consulta Safe Browsing y ayuda a detectar homoglyphs, enlaces raros y dominios que imitan marcas reales.

4. Responde y avisa

Si Gemini falla, entra el fallback local; si el riesgo es alto, la extensión actualiza badge y muestra notificación.
